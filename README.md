# Sonaway Systems

Adapted from the complete Sonaway.com source at commit 8e32dd6ada69fa4b1614a4585537e1a9f228ac16. The original component structure, SVG icons, styling layers, motion and interactive models are retained. Content and palette serve knowledge capture, SOP reconciliation, existing-platform setup and custom systems.

Static site: deploy the repository root. Example pricing is illustrative. Demo data is fictional. The contact form opens the visitor’s email application.

Run the inherited model checks with node --test tests/*.test.js.

The public Q&A uses PHP 8.1+, MariaDB, Cohere and OpenRouter. See [Q&A operations](ask/OPERATIONS.md) for the approved content, private configuration and indexing workflow.
